# Aesthetic Styles Catalog & Decision Matrix

Use this reference to recommend and implement the optimal visual style (or hybrid combination) for a project while preserving its existing brand palette.

| Style | Visual Characteristics | Best Fit / Use Cases | Key CSS Tokens & Techniques | Risks / Trade-offs |
| :--- | :--- | :--- | :--- | :--- |
| **Bento Grid** | Modular rounded cells, asymmetric/symmetric grid spans, subtle `1px` borders, clear micro-headers per cell. | Multi-step forms, academic/fintech portals, dashboards, WordPress embeds. | `display: grid; gap: 1rem; border-radius: 16px; border: 1px solid rgba(brand, 0.12); background: #fff;` | Can feel fragmented if cells lack visual hierarchy. |
| **Liquid Glass / Glassmorphism** | Translucent layered surfaces, frosted background blur, specular top/left border highlights, soft colored shadows. | Sticky headers, wizard steppers, interactive selection pills, floating action bars. | `background: rgba(255,255,255,0.78); backdrop-filter: blur(14px) saturate(160%); border: 1px solid rgba(255,255,255,0.6);` | Must maintain WCAG AA contrast; provide solid fallback for low-end GPUs and `@media print`. |
| **Swiss Editorial / Soft Brutalism** | High-precision grids, exposed hairlines/dashed ticket dividers, `tabular-nums` monospace metadata, stamp badges. | Official receipts, cryptographic tickets, audit logs, academic transcripts. | `font-variant-numeric: tabular-nums; border: 1.5px solid #0f172a; border-bottom: 2px dashed #94a3b8;` | Full raw brutalism can intimidate non-technical users; best used for tickets/receipts or hybridized. |
| **Minimalism** | Generous whitespace, restrained palette, typography-driven hierarchy, zero decorative noise. | High-conversion forms, institutional services, accessibility-first tools. | Neutral slate surfaces (`#f8fafc`), single accent color, subtle focus rings (`0 0 0 3px`). | Can look generic if micro-interactions and typography are not finely tuned. |
| **Claymorphism** | Soft 3D inflated surfaces, dual inner shadows (light top-left, dark bottom-right), rounded friendly shapes. | Consumer apps, educational onboarding, playful micro-widgets. | `border-radius: 24px; box-shadow: 0 10px 20px rgba(0,0,0,0.08), inset 0 -4px 8px rgba(0,0,0,0.06), inset 0 4px 8px #fff;` | Too playful for formal legal/academic declarations if overused. |
| **Spatial UI** | Depth-based layering, ambient luminance, floating glass panels with scale/z-axis focus states. | Immersive web apps, media portals, next-gen desktop workspaces. | Multi-layer `box-shadow`, `backdrop-filter`, subtle `transform: translateY(-2px) scale(1.01)` on focus. | Requires careful adaptation for print stylesheets and narrow mobile viewports. |
| **Neo-Futurism / Maximalism** | High-energy gradients, neon accents, kinetic typography, dense visual storytelling. | Creative portfolios, gaming, tech events, marketing landing pages. | Vibrant radial gradients, glowing borders, bold display fonts. | High cognitive load for utility/transactional forms. |

## Recommended Hybrid Pattern for Institutional & Transactional Web Apps
Combine **Bento Grid** (structural layout of form groups) + **Subtle Liquid Glass** (interactive stepper, active pills, and context banners) + **Swiss Editorial Ticket** (printable cryptographic receipt). This delivers modern visual polish while preserving institutional trust, mobile speed, and WCAG 2.1 AA compliance.
